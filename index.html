Cara install.

Dotfiles itu personal — baca dulu, lalu cherry-pick yang kamu butuhkan. Jangan salin semuanya mentah-mentah. Prasyarat: EndeavourOS atau Arch Linux, plus fish terpasang sebelum menjalankan install script.

Clone ke ~/.local/share/caelestia — posisi yang direkomendasikan upstream, karena install script membuat symlink ke semua config. Repo tidak boleh dipindah setelah install.

git clone https://github.com/dezzorigin/dotfiles.git ~/.local/share/caelestia
cd ~/.local/share/caelestia
./install.fish --vscode=codium --aur-helper=yay

Opsi lain: --spotify, --discord, --zen, --noconfirm. Daftar paket lengkap ada di .local/share/caelestia/README.md.

Pasang Ax-Shell di ~/.config/Ax-Shell — bar, launcher, dan dashboard di atas Fabric.

bash .config/Ax-Shell/install.sh
# mencopot: bash .config/Ax-Shell/uninstall.sh

Script ini memasang paketnya sendiri (fabric, matugen, cava, hypridle, hyprlock, playerctl, dan lain-lain).

Hanya mau meniru sebagian? Salin folder yang dibutuhkan saja.

git clone https://github.com/dezzorigin/dotfiles.git
cd dotfiles
cp -r .local/share/* ~/.local/share/
cp -r .config/* ~/.config/

Login manager (mis. greetd + tuigreet) dipasang terpisah — dotfiles ini tidak menyertakannya.

Tombol yang paling sering ditekan.

Satu meja kerja yang keyboard-driven: tiap keycap di bawah ini tombol fisik di keyboard, bukan hiasan. Daftar lengkap ada di hyprland/keybinds.conf.

  • Super + TTerminal (foot)
  • Super + WBrowser (Zen)
  • Super + CIDE (VSCodium)
